## ポモドーロタイマー

25分作業・5分休憩を繰り返す、シンプルで使いやすいポモドーロタイマーです。

### 主な機能

- 作業と休憩を自動で切り替えながらカウントダウン
- 各フェーズの終了時にビープ音で通知
- 完了した作業セッション数を表示
- ライト/ダーク両テーマに対応したシンプルなデザイン

### 使い方

1. フォルダをダウンロードまたはクローンしたら、`index.html` をダブルクリックするか、ブラウザで開いてください。
   - macOS や Windows でダブルクリックして開けない場合は、ブラウザのウィンドウに `index.html` をドラッグ＆ドロップすると表示できます。
   - コマンドラインが使える場合は、フォルダで `python3 -m http.server` を実行し、表示された `http://localhost:8000` をブラウザで開いても OK です。
2. 「スタート」を押すと作業カウントが始まり、作業終了後に自動で休憩へ切り替わります。
3. 一時停止・再開は「一時停止／再開」ボタンで行えます。
4. 「リセット」を押すと作業カウントとセッション数が初期化されます。
